# 前端精简与性能优化（第6号整合）

本次以完整WPF + API + SQL Server/SQLite双模式的主分支为基线，仅优化客户端请求和状态逻辑，不修改API公共契约及数据库迁移。

## 具体改动
- **切换学期**：只重新获取选中学期的课表/成绩/考试数据，不重复请求学期列表；手动点击刷新按钮仍会重新请求学期列表，保证用户可主动获取新增学期。
- **过滤课表**：在每次后端结果载入后只建立一次CourseRow对象；切换周次或“全部课程”筛选时复用，仍保持周一到周日的排序。
- **选中状态**：周次筛选后，若原课程仍在结果里则保留选中，避免编辑按钮突然失效。
- **页面导航**：重复点击已显示页面不再触发额外HTTP刷新；不同页面切换仍按原有流程刷新。
- **数据来源**：主窗口从GET /api/v1/data-status读取真实Provider，不再将SQL Server演示模式错误标为SQLite；健康检查与数据状态并发读取以减少串行等待。
- **代码精简**：移除仅返回Task.CompletedTask的同步页面清理包装方法。

## 测试
- 新增行为断言：切换学期不重复发GET terms，手动刷新重新获取；原有过期响应保护、成绩null、课表编辑和HTTP会话验证保持不变。
- 将行为断言放进Windows EXE发布CI门槛，成功后再生成并上传exe包。
- 同时要求原有后端真实HTTP smoke test通过。

## 边界
GitHub CI能验证编译、WPF ViewModel和exe打包，但在用户Windows电脑上的鼠标/键盘手动体验和SQL Server实例连接仍需本地验收。
