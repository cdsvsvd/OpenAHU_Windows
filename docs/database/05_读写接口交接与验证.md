# 成员05第二阶段：数据库读写已实现

日期：2026-11-05。当前分支：feat/database；基线main为8dd479eb63704b0bfb37d591bda30b3c535ac75f。当前更改仍在本地，未提交、未推送GitHub。

## 1. 本次完成的功能

- 8个仓储：IAppSettingsRepository、IStudentRepository、ITermRepository、ICourseRepository、IEnrollmentRepository、IGradeRepository、IExamRepository、ILinkRepository。
- IUnitOfWork：跨课程、周次、选课的同一数据库事务；仓储和事务均Scoped并共享CampusDbContext。
- 资料、学期、课程、成绩、考试、链接查询。个人数据按4号传入的活动学生和学期筛选，不向上层返回EF实体。
- Course.Weeks聚合为WeekNumbers；数据库周日7与领域周日0在仓储边界转换一次；保留null成绩、decimal字段和时间偏移。
- 新增课程及周次，再建立选课关系；Id沿用Application生成值。
- 编辑课程字段，先删除旧周次再写入新集合。支持同一作用域反复编辑、重叠周次替换，保留CourseCode和选课关系。
- 删除课程及周次/选课关系，返回是否删除。正常关联冲突由4号拒绝，数据库写入另加原子条件，保护检查后新增的成绩/考试。
- 幂等增加选课关系，仅忽略重复复合主键，不忽略外键失败。
- 包装数据库错误为CampusStoreUnavailableException，消息不含路径；失败和取消回滚，清理跟踪状态，原始业务异常不被回滚失败覆盖。

不在仓储内开嵌套事务。脱离IUnitOfWork直接调用写方法会被拒绝，避免产生半套数据。

## 3. 给3号的接入方式

Api项目引用Application与Infrastructure。保持Api→Application的业务调用，Infrastructure只在Composition Root配置。

```csharp
using OpenAHU.Infrastructure;
using OpenAHU.Infrastructure.Persistence;
using OpenAHU.Application.Abstractions.Queries;
using OpenAHU.Application.Abstractions.Commands;
using OpenAHU.Application.Services;

builder.Services.AddInfrastructure(builder.Configuration);
builder.Services.AddScoped<ActiveStudentProvider>();
builder.Services.AddScoped<IProfileQuery, ProfileQuery>();
builder.Services.AddScoped<ITermQuery, TermQuery>();
builder.Services.AddScoped<ICourseQuery, CourseQuery>();
builder.Services.AddScoped<IGradeQuery, GradeQuery>();
builder.Services.AddScoped<IExamQuery, ExamQuery>();
builder.Services.AddScoped<ILinkQuery, LinkQuery>();
builder.Services.AddScoped<IDataStatusQuery, DataStatusQuery>();
builder.Services.AddScoped<ICourseCommand, CourseCommand>();

// 构建app后、宣布客户端可加载之前执行；失败时由3号选择starting/degraded或退出。
var database = app.Services.GetRequiredService<CampusDatabase>();
var initialization = await database.InitializeAsync(app.Lifetime.ApplicationStopping);

// 健康端点实际调用CheckAsync，以IsReady构造HealthDto.DatabaseReady。
```

`AddInfrastructure`已注册全部仓储与IUnitOfWork，不要重复注册成Singleton。正常业务注入接口即可；不得在每个仓储里用IDbContextFactory创建不同上下文。现有Singleton factory保留给初始化/独立健康探针。

配置键仍是OpenAHU:DatabasePath，默认当前用户LocalAppData/OpenAHU/campus.db。Api只映射领域模型和错误，不直接执行SQL。
