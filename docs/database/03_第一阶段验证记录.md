## 27项测试覆盖

- 健康探针在缺库时不创建文件。
- 首次迁移、表关系、演示数量、模型与迁移一致。
- 重复初始化不覆盖修改，不恢复已删除课程。
- 课程、周次、选课关系在关闭并重新打开上下文后保留。
- 多步骤事务的后续写入失败后，之前保存的课程/周次/选课全部回滚。
- 未管理的既有数据库、未来迁移版本、损坏文件、缺表均被识别。
- 已有自定义记录即使没有seed标记也不会被演示数据覆盖。
- 外键、复合主键、星期/节次边界、最多一个当前学期。
- 成绩null、decimal学分、DateOnly、带时区偏移时间的存取。
- 不同偏移的考试时间约束按实际先后判断。
- 数据库写锁、只读文件、残留迁移锁、主动取消。
- 在可丢弃测试库上回退首次迁移到0，再通过迁移重建。
- 新建Windows数据库目录的当前用户ACL。
- 空路径、相对路径在打开数据库前被拒绝。

## 当前这台电脑怎样重跑

系统默认的 dotnet 仍是9，准备好的10在仓库外工作目录。因此，从本仓库根目录重跑时使用：

```powershell
& '..\work\member05\Invoke-DotNet.ps1' test src/OpenAHU.Infrastructure/Verification/OpenAHU.Infrastructure.Verification.csproj -c Release
```

重新查看已生成的演示验证库：

```powershell
$taskDatabase = [IO.Path]::GetFullPath((Join-Path (Get-Location) '../work/member05/demo-run/campus.db'))
& '..\work\member05\Invoke-DotNet.ps1' run --project src/OpenAHU.Infrastructure/Tools/OpenAHU.DatabaseTool.csproj -c Release -- --database-path $taskDatabase --check-only
```

该演示验证库因跨进程测试而有5门课程；全新迁移初始化的标准数量是4门。此脚本和验证库用于本机开发，不需提交仓库；其他成员安装 .NET10 后使用标准 dotnet 命令即可。
