## 给3号：已提供的接入点

```csharp
// 在 Api Composition Root 中由3号加入项目引用，并协作接入：
builder.Services.AddInfrastructure(builder.Configuration);

// 构建服务容器后、允许客户端进入就绪状态之前：
var database = app.Services.GetRequiredService<CampusDatabase>();
var initialization = await database.InitializeAsync(cancellationToken);

// 健康检查必须实际调用；DatabaseReady 依据 IsReady，不能固定返回 true：
var check = await database.CheckAsync(cancellationToken);
```

命名空间：`OpenAHU.Infrastructure` 和 `OpenAHU.Infrastructure.Persistence`。

配置：`OpenAHU:DatabasePath`，未设置时为当前用户 `%LocalAppData%/OpenAHU/campus.db`。测试可以通过 CampusDatabaseOptions 指定临时路径及超时。

初始化失败时如何保持 starting/degraded、是否退出进程，以及如何转成 db_unavailable，由3/4号确定。3号不在端点里直接执行 SQL，也不把数据库内部类型作为公共响应。
